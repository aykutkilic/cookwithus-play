# cookwithus

Cozy multiplayer cooking in the browser: cook real recipes together, with your own hands, in a lit
3D kitchen.

**Play: https://aykutkilic.github.io/cookwithus-play/**

You land in your own kitchen; invite friends with the code or link (WhatsApp, Telegram, share).
Walk with WASD / the arrow keys (or the stick on phones), press E / Use at a counter, the sink or
the stove, and every slice, scrub, stir and pour is yours to do.

This repository only holds the built game that GitHub Pages serves.
